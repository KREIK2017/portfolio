# ТЗ: Сайт-портфоліо в стилі Disco Elysium

## 1. Мета

Зробити персональний сайт-портфоліо, де **сама форма подачі є атракціоном**, а не звичайний сайт із блоками «про мене / навички / проекти». Аналог за духом — портфоліо, стилізовані під інтерфейс VS Code: людина взаємодіє з інтерфейсом, а не просто читає. Тут інтерфейс і атмосфера натхненні грою **Disco Elysium**: олійна painterly-графіка, приглушена палітра, ар-нуво типографіка, «голоси навичок» як внутрішній монолог.

Головна ідея: відвідувач не гортає стрічку, а **досліджує простір** і чує внутрішні голоси, які реагують на його дії.

## 2. Концепція: «Номер готелю» + голоси навичок

**Каркас — ізометрична кімната.** Сайт відкривається сценою пробудження в номері готелю (відсилка до початку гри). Кімната і є навігацією. Інтерактивні об'єкти в кімнаті = розділи сайту:

- **Дошка з нотатками / коркова дошка** → Проекти (головний розділ)
- **Дзеркало** → Про мене / «Хто ти»
- **Радіо** → Контакти
- **Валіза** → Резюме / CV (кнопка завантаження PDF)
- **Пляшка / попільничка на підлозі** → Фан-факти, «пасхалки»
- **Вікно** → перемикач дня/ночі (зміна настрою сцени, опційно)

**Наскрізна механіка — голоси навичок.** По всьому сайту, коли користувач наводить курсор або відкриває розділ, збоку спливають короткі репліки «навичок» кольоровим текстом — як внутрішній монолог у грі. Набір навичок (адаптований під автора):

- `ЛОГІКА` — архітектура, backend, чистий код
- `ВІЗУАЛЬНИЙ СМАК` (Savoir Faire/Perception) — UI, естетика
- `ЕМПАТІЯ` — UX, дослідження користувачів
- `ДРАМА` — сторітелінг, копірайт, презентація
- `ЕНЦИКЛОПЕДІЯ` — технічні знання, деталі
- `КІНЕСТЕТИКА` — анімації, інтеракції, «відчуття» продукту

Кожна навичка має свій колір репліки. Репліки — короткі (1–2 речення), з характером (іронічні, меланхолійні, самокритичні), у дусі гри.

**Розкриття проекту.** Клік по дошці → відкривається панель проектів. Кожен проект подається як «справа»/картка з коротким описом, стеком, роллю автора, результатом і посиланнями. Опційна геймова деталь: при відкритті найсильнішого кейсу — анімація «перевірки навички» (red/white check) з двома кубиками d6 та підсумком «успіх».

## 2.1 Доступність подачі: подвійний режим, підказки, affordances

**Критично:** імерсивна кімната не повинна ставати бар'єром для людини, яка не грала в ігри й просто хоче швидко переглянути навички та проекти. Контент **ніколи не замкнений за гіммічком**. Реалізувати три речі:

- **Подвійний режим.** Завжди видимий ненав'язливий перемикач **«Швидкий перегляд / Résumé»**, який веде на класичну, спокійну версію того самого контенту: звичайний вертикальний сайт із секціями «Проекти / Навички / Про мене / Контакти» в тій самій палітрі й шрифтах, але **без гри й важкого 3D**. Вибір режиму зберігається (cookie/localStorage). Обидва режими показують ідентичний контент.
- **Онбординг-підказка.** При першому вході в кімнату — короткий рядок-підказка (напр. «Оглянься. Клікай на предмети — або перейди одразу до résumé»), що зникає після першої взаємодії.
- **Affordances (сигнали інтерактивності).** Клікабельні об'єкти кімнати мають: м'яке пульсуюче світіння, зміну курсора на pointer, tooltip із назвою розділу при наведенні (дошка → «Проекти», дзеркало → «Про мене» тощо). Людина має за секунду зрозуміти, що з кімнатою можна взаємодіяти.
- **Постійна міні-навігація.** Тонке меню в кутку (Проекти / Про мене / Контакти / Résumé), доступне завжди поверх кімнати — швидкий шлях до інформації повз гру.

## 3. Структура та екрани

1. **Інтро / пробудження.** Чорний екран → проступають розрізнені репліки навичок (typewriter-ефект) → плавно проявляється кімната. Кнопка/автоперехід «розплющити очі».
2. **Кімната (хаб).** Ізометрична сцена з інтерактивними об'єктами. Підказка при першому вході («Озирнись. Клікай на предмети.»).
3. **Проекти.** Панель/оверлей поверх кімнати зі списком проектів + детальна картка проекту.
4. **Про мене.** Панель у стилі «character sheet»: навички з рівнями, коротка біографія від першої особи.
5. **Контакти.** Панель «радіо»: email, GitHub, LinkedIn, Telegram тощо, стилізовані під частоти/станції.
6. **Резюме.** Кнопка завантаження PDF.

Навігація: із будь-якої панелі — кнопка «назад до кімнати» (стилізована, напр. «Піти геть» / стрілка ар-нуво).

## 4. Візуальна система

**Палітра (hex):**

- Фон-основа (темна олія): `#1c1a17`, тепла тінь `#2b2620`
- Панелі / папір: `#d9c9a3`, `#c4b189` (вигоріла охра)
- Акценти: теракота `#b5654a`, бірюзово-зелений `#3e6157`, бурштин `#c9973f`
- Винний (red check / небезпека): `#7a2e2e`, `#8c3b32`
- Успіх (white check): `#5a7d5a`
- Текст світлий: `#e8ddc4`

Кольори реплік навичок — розподілити по акцентах вище (кожній навичці свій).

**Типографіка (Google Fonts):**

- Заголовки: декоративний ар-нуво serif — `Marcellus` або `Cormorant` / `Playfair Display`
- Основний текст: humanist serif — `Lora` або `Spectral`
- Мітки інтерфейсу (навички, статуси): вужчий шрифт, напр. `Cormorant SC` або letter-spaced caps

**Текстури та ефекти:**

- Painterly фон з ефектом олійних мазків + film grain (SVG `feTurbulence` фільтр або PNG-оверлей)
- Легкий вінʼєтинг по краях екрана
- Тонкі орнаментальні рамки/розділювачі в дусі ар-нуво
- М'яке приглушене світіння навколо активних об'єктів
- **Без яскравого неону, без чистих насичених кольорів** — усе приглушене, десатуроване

**Мікроанімації:**

- Typewriter-ефект для реплік навичок і діалогових текстів
- Плавне проступання/зникнення панелей (fade + subtle scale)
- Підсвічування об'єктів кімнати при наведенні (glow + легкий зсув)
- Анімація кубиків для скіл-чеків (обертання → зупинка на значенні)
- Повільні, «важкі» переходи — атмосфера меланхолії, не різкі

## 5. Технічні вимоги

- **Стек:** **React + Next.js** (App Router, TypeScript). Стилізація — Tailwind CSS або CSS Modules (на вибір виконавця; палітра з розділу 4 винесена в токени/CSS-змінні). Анімації та інтерактив — набір бібліотек із розділу 5.3.
- **Дані проектів і тексти** — винесені в окремі типізовані файли/модулі (напр. `content/projects.ts`, `content/skills.ts`) та у словники локалізації, щоб легко редагувати без правок компонентів.
- **Без власного бекенду.** Сайт статичний/edge-рендер; за потреби форм — через Cloudflare (напр. Workers), але базово бекенд не потрібен.
- **Адаптивність:** десктоп — повноцінна ізометрична сцена; на мобільному — коректний фолбек (напр. вертикальний список об'єктів-розділів зі збереженням стилю; ізометрію можна спростити). Сайт має бути юзабельним на телефоні.
- **Продуктивність:** `next/image` для оптимізації зображень (WebP/AVIF), lazy-load важких ассетів, плавні 60fps анімації, добрий Lighthouse-score.
- **Доступність:** контраст тексту читабельний, keyboard-навігація по інтерактивних об'єктах, `alt` для зображень, семантичний HTML, `prefers-reduced-motion` — вимикати важкі анімації.
- **SEO:** коректні метатеги через Next.js Metadata API, `hreflang` для двох мов, `sitemap.xml`, Open Graph превʼю.
- **Браузери:** актуальні Chrome, Firefox, Safari, Edge.

### 5.1 Локалізація (i18n) — дві мови: англійська та українська

- Підтримка **EN** та **UK** через i18n-роутинг Next.js (напр. `next-intl` або вбудований i18n App Router): маршрути `/en/...` та `/uk/...`.
- **Перемикач мови** у самому інтерфейсі, стилізований під загальний вигляд (напр. окремий елемент у кімнаті або в кутку сцени). Вибір мови зберігається (cookie/localStorage).
- **Увесь контент двомовний**: репліки навичок, описи проектів, тексти розділів, підписи, кнопки. Словники — окремі файли (`messages/en.json`, `messages/uk.json`).
- Мова за замовчуванням і визначення за `Accept-Language` з можливістю ручного перемикання.
- `<html lang>` та `hreflang` відповідають активній мові.

### 5.2 Деплой

- **Хостинг:** **Cloudflare Workers** (Next.js через `@opennextjs/cloudflare` / OpenNext, або Cloudflare Pages-сумісний білд — на розсуд виконавця, головне робочий edge-деплой на Workers).
- **Домен:** `kreik.pp.ua` (продакшн). Налаштувати DNS/маршрути в Cloudflare, HTTPS, редірект з кореня на дефолтну локаль за потреби.
- **Репозиторій:** README з інструкціями `dev` / `build` / `deploy`; конфіг Wrangler (`wrangler.toml`) і потрібні змінні середовища задокументовані.

### 5.3 Анімації та інтерактив (бібліотеки)

- **Spline** (`@splinetool/react-spline`) — інтерактивна **3D-сцена кімнати** на десктопі: реальне світло, глибина, легкі рухи об'єктів при наведенні/скролі. Замінює/доповнює плаский ізо-арт, прибирає відчуття статичної декорації.
  - Обов'язково **lazy-load** (динамічний імпорт, не в перший бандл), прелоадер у стилі сайту.
  - **Фолбек:** на мобільних, при повільному з'єднанні або `prefers-reduced-motion` — не вантажити Spline, показувати статичну ілюстрацію/спрощену сцену.
  - Слідкувати за вагою сцени та FPS; тримати сцену максимально легкою.
- **Lenis** (`lenis`) — плавний інерційний скрол для класичної версії та мобільного «досьє» (кінематографічність). Обов'язково поважати `prefers-reduced-motion` (вимикати) і не ламати нативний скрол на тач-пристроях; коректна робота з фіксованими елементами й якорями.
- **anime.js** — імперативні мікроанімації: пульс світіння на клікабельних об'єктах (affordances), typewriter реплік навичок, анімація кубиків скіл-чеків, переходи панелей/оверлеїв, дрібні акценти.
- **Узгодження:** уникати дублювання. anime.js — для таймлайн/імперативних ефектів; для enter/exit React-компонентів можна Framer Motion АБО anime.js — обрати щось одне, щоб не роздувати бандл. Стежити за загальною вагою JS (code-splitting, вантажити важке лише там, де потрібно).

### 5.4 Мобільна версія (adaptive, а не просто responsive)

- На телефонах **не стискати ізометричну/3D-сцену** — дрібні хотспоти незручні й важкі. Замість цього — **окремий адаптивний макет**, що зберігає естетику Disco Elysium (палітра, шрифти, текстури, репліки навичок при скролі), але дає нормальну навігацію:
  - Кімната стає або компактним нерухомим «постером»-хедером угорі, або зовсім прибирається.
  - Нижче — звичайний **вертикальний скрол** із секціями «Проекти / Навички / Про мене / Контакти», великі тач-таргети, плавний скрол через Lenis.
  - Репліки навичок з'являються при скролі як атмосферні вставки, а не hover-tooltip (на тач немає hover).
- Десктоп = імерсивна 3D-кімната; мобайл = елегантне «досьє», що тримає настрій, але працює як звичайний швидкий сайт.
- Тестувати на реальних розмірах (360–430px ширини), перевірити продуктивність і відсутність горизонтального скролу.

**Графіка кімнати:** реалізувати ізометричну/3D-сцену через Spline (розділ 5.3), АБО як шарувату ілюстрацію (PNG/SVG у заданій палітрі) з clickable-hotspots поверх. Якщо готового арту/сцени немає — використати плейсхолдери-заглушки в правильній палітрі та лишити коментарі, куди підставити фінальні ассети. (Фінальний арт автор може згенерувати окремо або зібрати сцену в Spline під цю палітру.)

## 6. Контент (плейсхолдери — заповнити реальними даними)

> Автору: підстав свої дані замість заглушок нижче.

**Проекти** (для кожного): назва, 1–2 речення опису, роль, стек технологій, результат/метрика, посилання (live / GitHub), 1 зображення/скріншот.

- Проект 1: `[назва]` — `[опис]` — `[стек]` — `[результат]` — `[лінк]`
- Проект 2: `...`
- Проект 3: `...`
- (додати всі)

**Про мене:** `[коротке біо від першої особи, 3–5 речень]`, рівні навичок (значення 1–6 для кожної з 6 навичок для «character sheet»).

**Контакти:** email `[...]`, GitHub `[...]`, LinkedIn `[...]`, Telegram `[...]`.

**Резюме:** файл `cv.pdf` `[додати]`.

**Тексти реплік навичок:** написати по 3–5 коротких реплік на кожну навичку (можна доручити згенерувати в стилі гри, потім відредагувати).

> **Увага:** весь контент цього розділу потрібен **двома мовами — EN та UK**. Складати одразу в словники локалізації (`messages/en.json`, `messages/uk.json`).

- [ ] Ізометрична кімната з мінімум 5 інтерактивними об'єктами; кожен веде у свій розділ.
- [ ] Голоси навичок спливають при наведенні/відкритті, кольорові, з typewriter-ефектом.
- [ ] Розділ проектів: список + детальні картки з усіма полями та посиланнями.
- [ ] Про мене (character sheet), Контакти (радіо), Резюме (завантаження PDF) реалізовані.
- [ ] Витримана палітра, шрифти, текстури, вінʼєтинг — атмосфера Disco Elysium, без неону.
- [ ] **Подвійний режим** (кімната ⇄ «Швидкий перегляд / Résumé») працює; контент ідентичний, вибір зберігається.
- [ ] **Affordances**: клікабельні об'єкти світяться/мають pointer і tooltip; є онбординг-підказка; постійна міні-навігація доступна.
- [ ] **3D-сцена (Spline)** з lazy-load і статичним фолбеком; не вантажиться на мобайл/`reduced-motion`/повільний зв'язок.
- [ ] **Lenis** плавний скрол працює й поважає `prefers-reduced-motion`; **anime.js** ефекти (світіння, typewriter, кубики) на місці; бандл під контролем.
- [ ] **Adaptive-мобайл**: окремий макет (не стиснута сцена), нормальна навігація, великі тач-таргети, немає горизонтального скролу, добра продуктивність.
- [ ] `prefers-reduced-motion` вимикає важкі анімації; базова keyboard-доступність.
- [ ] **Двомовність EN/UK**: працює перемикач, увесь контент перекладено, роутинг `/en` та `/uk`, `hreflang` коректні.
- [ ] Задеплоєно на **Cloudflare Workers**, домен **kreik.pp.ua** працює по HTTPS, README з інструкцією.
- [ ] Дані й переклади винесені окремо (легко редагувати проекти, тексти, обидві мови).

## 8. Порядок робіт (рекомендований)

1. Ініціалізація Next.js (App Router, TS), Tailwind/CSS-модулі, палітра як токени, підключення шрифтів.
2. Налаштування i18n (EN/UK) — роутинг, словники, перемикач мови.
3. **Класична версія («Швидкий перегляд / Résumé») + подвійний режим** — спочатку робочий базовий контент, доступний завжди.
4. Система панелей/оверлеїв і навігація «кімната ⇄ розділ» + постійна міні-навігація.
5. Сцена кімнати: Spline 3D (lazy-load + фолбек) або ізо-плейсхолдери; affordances (світіння, tooltip, онбординг).
6. Механіка голосів навичок (типізовані дані + рендер + typewriter через anime.js, обидві мови).
7. Наповнення розділів (проекти, про мене, контакти, резюме) з перекладами.
8. Текстури, вінʼєтинг, мікроанімації (anime.js), Lenis-скрол, скіл-чек з кубиками.
9. **Adaptive-мобайл** (окремий макет) + доступність + `prefers-reduced-motion` + SEO/hreflang.
10. Деплой на Cloudflare Workers, підключення домену kreik.pp.ua, README.

## 9. Примітки

- Концепцію «кімнати» за бажанням можна замінити на альтернативну (повне діалогове дерево зі скіл-чеками, або «Thought Cabinet» — сітка проектів-«думок»), зберігаючи ту саму візуальну систему з розділу 4. Якщо обрано альтернативу — попередити автора.
- Пріоритет: **атмосфера й оригінальність подачі** важливіші за кількість фіч. Краще менше розділів, але кожен «живий».
