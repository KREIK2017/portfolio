# kreik.pp.ua — портфоліо

Два режими подачі того самого контенту:

- **Résumé** (`/`, `/en/`) — режим за замовчуванням. Спокійна класична версія
  за мокапом «MY STACK»: ліва панель, секції, сітка технологій. Саме це бачить
  той, хто зайшов швидко подивитися роботи.
- **Кімната** (`/room/`, `/en/room/`) — імерсивна ізометрична сцена в стилі
  Disco Elysium. Предмети є навігацією, «голоси навичок» комментують дії.

Перемикач видимий у обох режимах, вибір зберігається в `localStorage`
(ключ `kreik-mode`): хто раз обрав кімнату, того корінь одразу веде туди.

Next.js 16 (App Router) + Tailwind CSS 4, статичний експорт.
Хостинг — Cloudflare Workers (static assets), домен і DNS — Cloudflare.

## Запуск

```bash
npm run dev     # http://localhost:3000
npm run build   # збірка статики в out/
npm run lint
```

## Технічні рішення

**Дві палітри, одні токени.** Кімната використовує змінні `--de-*` (темна
олія), résumé — `--rs-*` (світлий папір). Вони не перетинаються, тому
режими не впливають один на одного.

**Картки стеку розмальовані алгоритмом.** Розкладено на чотири шари, щоб
кожен можна було правити окремо:

| Шар | Файл | За що відповідає |
| --- | --- | --- |
| Дані | `content/stack.ts` | палітри `base` + `accents`, рівні, описи |
| Алгоритм | `lib/paint/brushCard.ts` | мазки, патьоки, вінʼєтка, зерно, рваний кут |
| Рендер | `resume/StackCardArt.tsx` | полотно, DPR, перемалювання при ресайзі |
| Фільтр | `ui/LivingOilFilter.tsx` | «жива олія» — тремтіння мазків |

Алгоритм не знає нічого про сторінку — приймає 2D-контекст і палітру.
Тому його можна викликати і з React, і з Node-скрипта, якщо колись
захочемо запікати текстури під час збірки замість малювання в браузері.

Чотири відступи від початкового прототипу, кожен із причини:

- **малюнок детермінований** — seed рахується з `id` технології, тому
  картки не перемальовуються по-новому на кожному візиті;
- **зерно з однієї плитки 128×128** замість `getImageData` по кожній
  картці: на дванадцяти картках попіксельний прохід давав мільйони
  ітерацій і помітний фриз при завантаженні;
- **рваний кут вирізається в прозорість**, а не заливається кольором
  паперу — інакше картка прив'язана до одного фону;
- **константи множаться на масштаб** від розміру полотна, інакше на
  retina мазки виходять удвічі дрібнішими за задумані.

Фільтр застосований **тільки до полотна**, не до картки: `feDisplacementMap`
не розрізняє фарбу й літери, тому підпис поверх нього тремтів би й
розмивався. Анімація — `calcMode="discrete"`, бо `feTurbulence` рахується
на CPU. Деталі в комментарях `LivingOilFilter.tsx`.

**Кімната — не картинка, а геометрія.** `src/lib/iso.ts` рахує паралельну
проєкцію 30°, `Room.tsx` збирає сцену з кубів і площин. Масштабується без
втрат. Маркери й тултипи лежать окремим шаром поверх сцени — інакше
bounding box інтерактивної групи розтягувався до тултипа й браузер малював
фокусну рамку по всьому цьому прямокутнику.

**Двомовність без middleware.** У статичному експорті middleware не працює,
тому `Accept-Language` прочитати нічим. Замість цього — два root layout через
route groups: `(uk)` віддає `/`, `(en)` віддає `/en/`. Кожна версія має
правильний `lang` уже в статичному HTML і `hreflang` на другу.

**Шрифти й кирилиця.** ТЗ пропонувало `Marcellus` для заголовків і `Anton`
для класичного режиму — в обох немає кирилиці, український текст падав би
на системний шрифт. Тому `Cormorant` (кімната), `Oswald` (résumé), `Lora`
(текст) — усі з кирилицею.

**Lenis вантажиться динамічним імпортом** і лише в режимі résumé: кімнаті
скрол не потрібен, тож бібліотека не потрапляє в її бандл. При
`prefers-reduced-motion` не підключається взагалі.

**`prefers-reduced-motion` вимикається в логіці, а не лише в CSS.**
Медіа-правило не скоротить інтервал typewriter'а і не зупинить кубики,
тому стан читається через `usePrefersReducedMotion`.

**anime.js свідомо не використовується.** Світіння, typewriter і кубики
працюють на CSS і React; бібліотека додала б вагу без видимої різниці.

## Деплой

Сайт розгорнутий як **Cloudflare Worker зі статичними ассетами**.
`wrangler.jsonc` без поля `main`, тому серверний код не виконується —
Cloudflare роздає вміст `out/` зі свого CDN.

Кожен push у `main` перезбирає сайт через Workers Builds:

| Параметр       | Значення              |
| -------------- | --------------------- |
| Build command  | `npm run build`       |
| Deploy command | `npx wrangler deploy` |
| Root directory | `/`                   |
| Env var        | `NODE_VERSION` = `22` |

### Домен

- `kreik.pp.ua` — custom domain Workerʼа
- `www.kreik.pp.ua` — `A → 192.0.2.1` Proxied плюс Redirect Rule `301` на
  апекс зі збереженням шляху. Адреса зарезервована й нікуди не веде: запис
  існує лише щоб трафік дійшов до Cloudflare, де його перехоплює правило

Увімкнено `Always Use HTTPS`, інакше `http://www` не підпадає під правило
редиректу (воно описане як `https://www.kreik.pp.ua/*`) і віддає `522`.
